Antes de empezar

Qué necesitas

  • iPhone con iOS 17 o más recienteAjustes › General › Información › Versión de iOS.

Instalación

Paso a paso

Puedes ir marcando cada paso como hecho; se queda guardado si abres esta guía en Safari.

  1. Instala Scriptable

    1. Abre la App Store y busca Scriptable, de Simon Støvring. Es gratis.
    2. Instálala y ábrela una vez.

    Abrir Scriptable en la App Store

  2. Pega el instalador

    Este script descarga los otros dos y sirve después para actualizar.

    1. Copia el código de abajo. Usa el botón. Si no ves botón, mantén presionado el código y elige Seleccionar todo y luego Copiar.
    2. En Scriptable toca + arriba a la derecha y pega.
    3. Toca el título de arriba y ponle de nombre TiempoP Actualizar. Toca Done.
    4. Toca la tarjeta TiempoP Actualizar para ejecutarla.
    5. Debe salir TiempoP instalado con ✅ junto a TiempoP Registro y TiempoP Widget.
    // TiempoP Actualizar
// ------------------
// Instalador y actualizador. En un iPhone nuevo basta con pegar este script y
// ejecutarlo: descarga "TiempoP Registro" y "TiempoP Widget".
// Después, cada vez que lo ejecutes, trae la última versión desde GitHub y
// reemplaza los scripts conservando sus nombres. Tus datos no se tocan.

const BASE = "https://raw.githubusercontent.com/pabloecomsy/AppControlTiempoP/claude/vibrant-newton-uj9hl3/atajos-scriptable/";
const TARGETS = [
  { remote: "TiempoP%20Registro.js", match: /^tiempo\s*p\s*registro\.js$/i, fallback: "TiempoP Registro.js" },
  { remote: "TiempoP%20Widget.js",   match: /^tiempo\s*p\s*widget\.js$/i,   fallback: "TiempoP Widget.js" },
  { remote: "TiempoP%20Actualizar.js", match: /^tiempo\s*p\s*actualizar\.js$/i, fallback: "TiempoP Actualizar.js" },
];

// Los scripts se guardan junto a este mismo script, esté en iCloud Drive o en el
// iPhone. Así funciona igual en una instalación nueva (solo con este script pegado)
// que al actualizar.
function scriptsLocation() {
  const self = (typeof module !== "undefined" && module.filename) || "";
  if (self) {
    const fm = self.includes("Mobile Documents") ? FileManager.iCloud() : FileManager.local();
    return { fm, dir: self.slice(0, self.lastIndexOf("/")) };
  }
  try {
    const icloud = FileManager.iCloud();
    const d = icloud.documentsDirectory();
    if (icloud.listContents(d).some(n => /^tiempo\s*p/i.test(n))) return { fm: icloud, dir: d };
  } catch (e) {}
  const local = FileManager.local();
  return { fm: local, dir: local.documentsDirectory() };
}

const { fm, dir } = scriptsLocation();
const existing = fm.listContents(dir);
const existingCount = existing.filter(n => /^tiempo\s*p\s*(registro|widget)\.js$/i.test(n)).length;
const report = [];

for (const t of TARGETS) {
  const req = new Request(BASE + t.remote + "?t=" + Date.now());
  let code;
  try {
    code = await req.loadString();
  } catch (e) {
    report.push(`❌ ${t.fallback}: sin conexión`);
    continue;
  }
  if (!req.response || req.response.statusCode !== 200 || !code.includes("TiempoP")) {
    report.push(`❌ ${t.fallback}: descarga inválida`);
    continue;
  }
  const name = existing.find(n => t.match.test(n)) || t.fallback;
  fm.writeString(fm.joinPath(dir, name), code);
  const ver = (code.match(/const VERSION = "([^"]+)"/) || [])[1];
  report.push(`✅ ${name.replace(/\.js$/, "")}${ver ? "  v" + ver : ""}`);
}

const a = new Alert();
a.title = existingCount ? "TiempoP actualizado" : "TiempoP instalado";
a.message = report.join("\n") + "\n\nSi el widget no cambia de inmediato, espera unos minutos o quítalo y vuelve a ponerlo.";
a.addAction("OK");
await a.presentAlert();
Script.complete();

  3. Crea la primera automatización

    Le avisa a TiempoP cada vez que abres Instagram. Esta es la que más pasos tiene; las demás se copian de ella.

    1. Abre Atajos, ve a la pestaña Automatización y toca +.
    2. Si aparece «¿Qué quieres que haga tu atajo?», toca la X junto a la caja de texto y luego Editar.
    3. Toca Automatización, elige App, luego Instagram y deja solo Se abre. Debe quedar «Al abrir Instagram».
    4. Toca el > junto a Instagram. Deja Automatización encendido y Notificar apagado.
    5. En Buscar escribe Texto, agrega esa acción y escribe instagram abrir.
    6. En Buscar escribe Run Script y elige la de Scriptable. En Script elige TiempoP Registro.
    7. Mantén presionado el botón Parameter, elige Seleccionar variable y toca la caja Texto. Ahora Parameter debe decir «Texto».
    8. Toca el nombre de arriba, llámalo IG abrir y regresa con < para guardar.

    Si tocas Parameter rápido se abren tus archivos. Ciérralos y usa la caja Texto como dice el paso 7.

  4. Duplica para las otras cinco

    En la lista de Automatización, mantén presionada IG abrir y toca Duplicar. En cada copia cambia el disparador y el texto como dice la tabla.

    Importante: iOS apaga las copias. Arriba dirán «Automatización desactivada». Toca el > del disparador y enciende Automatización en cada una, o esa app nunca dejará de contar.

    ListoNombreDisparadorTexto
    IG abrirAl abrir Instagraminstagram abrir
    IG cerrarAl cerrar Instagraminstagram cerrar
    FB abrirAl abrir Facebookfacebook abrir

  5. Haz una prueba

    1. Usa Instagram uno o dos minutos y vuelve al inicio.
    2. Abre Scriptable y toca TiempoP Registro.
    3. Debe decir instagram: 1 min o 2 min, sin «(abierta)». En Últimos eventos deben aparecer instagram abrir y instagram cerrar.
    4. Si quieres empezar el día en cero, toca Reiniciar hoy.

  6. Pon los widgets

    Usa la combinación que elegiste arriba. Cada widget se configura igual; solo cambia el tamaño y lo que escribes en Parameter.

    1. Con la pantalla de bloqueo visible, mantén presionado el fondo y toca Personalizar y luego Pantalla de bloqueo.
    2. Toca la fila de widgets bajo la hora. Quita los que no quieras con –.
    3. Busca Scriptable y agrega el tamaño que toca: rectangular o circular.
    4. Toca el widget recién puesto. En Script elige TiempoP Widget y en Parameter escribe lo de tu tarjeta.
    5. Para el widget en línea, toca la fecha encima de la hora y repite lo mismo.
    6. Toca fuera de los menús y luego OK.

    En Script siempre va TiempoP Widget, nunca TiempoP Registro.

    Pantalla de inicio: mantén presionado el inicio, toca Editar › Agregar widget › Scriptable › Mediano y configúralo igual.

  7. Ajusta tus metas

    Opcional. Las metas solo colorean las barras y llenan los anillos; no bloquean nada.

    1. En Scriptable mantén presionada la tarjeta TiempoP Widget y elige editar.
    2. Cambia los minutos de esta línea, cerca del inicio:
    const GOALS = { instagram: 30, facebook: 30, chrome: 60 };

    Si después ejecutas TiempoP Actualizar, la línea vuelve a 30, 30 y 60. Ajústala otra vez.

Problemas comunes

Una app sigue sumando minutos aunque ya salí

Su automatización de «cerrar» está apagada. Abre esa automatización en Atajos; si arriba dice «Automatización desactivada», toca el > y enciéndela. Revisa también que el texto diga cerrar y no abrir.

El widget muestra un dato viejo

iOS decide cuándo redibuja los widgets, normalmente cada 5 a 20 minutos, y Atajos no puede forzarlo. El conteo sí se guarda al momento; solo el dibujo llega tarde. La hora act. te dice de cuándo es lo que ves.

Para actualizarlo al instante: en la configuración del widget cambia When Interacting a Run Script. Al tocarlo se abre Scriptable un segundo; ciérralo y el widget se pone al día.

Al tocar Parameter se abren mis archivos

Es normal. Ciérralos, agrega antes una acción Texto con lo que va escrito, y luego mantén presionado Parameter › Seleccionar variable › toca la caja Texto.

El widget dice que usa «TiempoP Registro»

Elegiste el script equivocado. Edita el widget y en Script elige TiempoP Widget.

En Últimos eventos aparece «no reconocido»

Una automatización corrió sin texto. Revisa que en las seis el Parameter diga «Texto» y que la caja Texto tenga lo de la tabla.

¿Cómo actualizo cuando haya mejoras?

Toca la tarjeta TiempoP Actualizar en Scriptable. Tus tiempos e historial no se borran.

Para que no haya sorpresas

Qué mide y qué no

  • Mide Instagram, Facebook y ChromeDesde que abres cada app hasta que sales, al segundo. Abrir una app cierra la sesión de las otras.
  • «Sin redes» no es «sin teléfono»iOS no deja que Atajos sepa cuándo desbloqueas. Mide cuánto llevas sin abrir esas tres apps.
  • Instagram desde Chrome cuenta como ChromeEl navegador no distingue qué página ves.
  • No mide el tiempo total del iPhonePara eso agrega el widget de Tiempo en pantalla que trae iOS.
  • Si se pierde un aviso de cierreLa sesión se corta sola a los 90 minutos para no inflar el día.
  • PrivacidadNo hay cuentas ni servidores. Los datos se guardan en Scriptable, en tu iPhone. El instalador solo descarga los scripts desde GitHub.
